How it's measured

The unmodified AA-AgentPerf-Local default replay: 8 recorded coding-agent tasks, 168 turns, with the conversation growing to about 56K tokens. One request at a time in a 65,536-token context, and every turn writes exactly its recorded number of tokens. Completion time adds up each turn from request to last token; tool calls are not timed.
